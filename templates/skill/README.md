# skill-name

One line: what it does.

- **Invoke:** `/<plugin>:skill-name [argument]` when installed as a plugin, or `/skill-name` when copied into a skills folder.
- **Produces:** the files, messages or changes it makes.
- **Cost:** rough token and time cost, and how many sub-agents it spawns.
