## Rules

Read `CONTRIBUTING.md` ("Conventions") and check changes against it. The ones most often broken:
- Money is stored and passed as integer minor units (cents), never floats.
- Every route checks the caller's permissions before it reads or writes anything.
- Every migration is reversible: it has a working down step, or says why it can't.
- No secrets or personal data in logs.

## Decided

Architecture decisions are in `docs/decisions/` (index in `docs/decisions/README.md`).

## Areas

`server/src/*`: one area per top-level folder. `web/src/pages`: one area. `deploy/`: one area.

## Focus

Migrations and anything touching sign-in.
